# Installation and Removal — Eval7

## Scope

This procedure applies only to the professor/university evaluation package:

`OMR_Current_Eval7_Professor_Installable.zip`

Expected ZIP SHA-256:

`e97eb321b15efd3068a9b10b9f3e399cb8b1a2495e33d8b5d82cb792ba347a23`

## Minimum platform

- Windows 10 version 1903 / build 18362 or newer
- 64-bit Windows (`x64compatible` installer target)
- Per-user installation; administrator rights are not required by the installer configuration

The current release is not claimed to support ARM64-native Windows, Windows Server, or every enterprise endpoint-security policy.

## Before installation

1. Download only from the GitHub Release page linked in `README.md`.
2. Verify the ZIP SHA-256 against `SHA256SUMS.txt`.
3. Keep Microsoft Defender / SmartScreen enabled.
4. Do not use real student data.
5. If Windows or endpoint security reports a named threat, stop and report it; do not force-run.

## Install

1. Extract the ZIP fully to a normal local folder.
2. Run:

   `OMR_Current_Eval7_Setup.exe`

3. Complete the installer wizard.
4. Launch `SSTAI OMR BRB001` from the Start Menu or the optional desktop shortcut.
5. Use the bundled demo/evaluation material first.

## Expected installation location

Default per-user location:

`%LOCALAPPDATA%\Programs\SSTAI\BRB001`

Runtime/evaluation data may be created under:

`%LOCALAPPDATA%\SSTAI-OMR`

Common subdirectories include `mobile_inbox`, `copier_imports`, `print_jobs`, `sessions`, `exams`, `batch_runs`, `copier_dedup`, `sheet_identity`, validation data, and institution/form-profile draft data.

## Uninstall

Use Windows Apps & Features / Installed Apps or the Start Menu uninstall entry generated by the installer.

The evaluation build uses an Inno Setup uninstall path. Uninstalling the application does not, by itself, guarantee deletion of all evaluation/runtime data under `%LOCALAPPDATA%\SSTAI-OMR`; preserve or remove that data according to the evaluation/data-handling policy.

## Failure conditions

Stop the evaluation and do not force-run if any of the following occurs:

- ZIP checksum mismatch;
- named antivirus or EDR detection;
- installer exits unexpectedly or fails to create the expected application files;
- dashboard fails to start;
- application attempts to use real student data without separate authorization;
- unexpected network, credential, or privilege request appears.

## Troubleshooting evidence to record

When reporting an installation problem, record:

- release tag;
- ZIP SHA-256;
- Windows edition/version/build;
- x64 architecture status;
- exact error message or detection name;
- screenshot when safe;
- whether installation, first launch, uninstall, or reinstall failed;
- redacted log paths if available.

Do not include passwords, tokens, private source, real student data, or sensitive institutional information in a public issue.
